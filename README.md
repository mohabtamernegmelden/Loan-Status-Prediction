# Loan-Status-Prediction
📌 Overview

This project builds a Machine Learning model to predict whether a loan application will be approved or rejected based on applicant information such as income, credit history, employment status, and loan amount.

The goal is to help financial institutions reduce risk by identifying high-risk applicants before approving loans.

This repository demonstrates a complete end-to-end ML pipeline, including data preprocessing, feature engineering, model training, evaluation, and performance optimization.

🎯 Problem Statement

Loan approval is a critical decision-making process in the banking sector. Incorrect approvals may lead to financial loss, while incorrect rejections may reduce customer satisfaction.

This project aims to:

Automate loan approval prediction

Minimize default risk

Improve decision-making using data-driven models
